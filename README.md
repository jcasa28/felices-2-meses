# Regalo web de 2 meses 💗

## Abrir
Abre `index.html` en Chrome, Safari o Firefox. No necesitas instalar nada.

## Personalizar
- `script.js`: edita `CONFIG` para poner tus 10 canciones, planes, restaurantes, películas y sorpresas.
- `index.html`: cambia los textos románticos y los nombres de las imágenes.
- `style.css`: cambia colores, tamaños y estilos.
- `images/nosotros.svg` y `images/recuerdo.svg` son imágenes de ejemplo. Para usar fotos reales, pon tus imágenes en `images/` (por ejemplo `foto1.jpg`) y cambia `src="images/nosotros.svg"` por `src="images/foto1.jpg"` en `index.html`.

## Publicar gratis
Puedes subir la carpeta a GitHub Pages o Netlify para compartir un enlace. Google Fonts necesita internet; el resto funciona localmente.
